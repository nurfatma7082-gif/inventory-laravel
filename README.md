# Inventory Management System - Laravel

Aplikasi web sistem manajemen inventaris berbasis web yang dibangun menggunakan **Laravel** dan **Bootstrap 5** untuk memenuhi tugas mata kuliah Pemrograman Web.

## 🚀 Fitur Utama
* **CRUD Barang (Item):** Menambah, melihat, mengedit, dan menghapus data inventaris barang.
* **MVC Architecture:** Menerapkan pola *Model-View-Controller* dengan *Resourceful Controller*.
* **Database Eloquent ORM:** Menggunakan MySQL PDO dengan pengamanan `$guarded = ['id']` untuk *Mass Assignment*.
* **Responsive UI:** Tampilan antarmuka yang bersih dan rapi menggunakan Bootstrap 5.

## 🛠️ Teknologi yang Digunakan
* **PHP** (v8.1+)
* **Laravel Framework**
* **MySQL** (via Laragon / XAMPP)
* **Bootstrap 5**
* **Git & GitHub**
